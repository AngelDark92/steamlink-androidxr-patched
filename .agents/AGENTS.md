# Project skill guidance

The repository-root `AGENTS.md` applies here. This repository ships patched Steam Link APKs as release assets, so work in it is release work, not build work.

- Release playbook: [`release-steamlink-apk`](skills/release-steamlink-apk/SKILL.md). Read it before creating, replacing, or deleting a release.
- Patch sources, build bases and changelog: [xr-porting-hub](https://github.com/AngelDark92/xr-porting-hub). This repository never rebuilds an APK.
- Driver compatibility is stated per release by the owner. If it is not stated, ask; never infer it from a driver release date.
